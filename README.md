# Freelancer Portfolio – Starter

This is a minimal starter for the assignment website (single shared CSS).

## Pages
- `index.html` (Home)
- `portfolio.html`
- `services.html`
- `blog.html`
- `contact.html`
- `css/styles.css` (shared)

## Suggested Workflow
1. **Create issues**: one per page; assign each to a different member.
2. **Branch from `develop`**: `git checkout -b feature/issue-<id>`
3. **Implement** only the assigned HTML and shared CSS.
4. **Commit & Push**; open a PR to `develop`, request reviews.
5. **Resolve conflicts** if any; team lead merges after approval.
6. **Release**: team lead creates `release/vX.Y.Z`, then PR into `main` with required approvals.

## Local Preview
Just open the `.html` files in your browser, or use a simple server:
```
python -m http.server 5173
# open http://localhost:5173
```
